# Contributing to Typing Trainer

Thank you for your interest in contributing to Typing Trainer! We welcome contributions that help improve the typing tutor for everyone.

## How to Contribute

1. **Fork and Branch:** Fork the repository on GitHub and create a new feature branch from `main`.
2. **Focused Changes:** Keep pull requests focused on a single feature, bug fix, or documentation update.
3. **Quality Verification:** Before opening a pull request, ensure that:
   - `npm run build` succeeds without errors.
   - All tests pass (`npm test`).
   - TypeScript checks pass with zero warnings or errors.
4. **Conventional Commits:** Use conventional commit message prefixes:
   - `feat:` for new features
   - `fix:` for bug fixes
   - `docs:` for documentation updates
   - `refactor:` for code refactoring
   - `test:` for test additions or updates

## Clean-Room Rule

All contributions must be 100% original work or under a compatible permissive open license:
- **Never submit code, text, lesson drills, images, or sounds copied from TypingMaster or any other proprietary software.**
- This project is developed using clean-room engineering principles. Violations of this policy will result in immediate rejection or reversion of the contribution.
